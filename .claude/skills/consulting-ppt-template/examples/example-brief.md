# Example brief: Finance Transformation Enabled by Enterprise AI

The brief behind `demo-storyboard.json` and `sample-deck.pptx`.

| Input | Value |
|---|---|
| Topic and objective | Finance transformation enabled by enterprise AI. Get steering-committee approval to fund wave 1. |
| Audience | CFO and finance steering committee of a mid-size bank. |
| Decision the deck supports | Fund wave 1 (close and controls), name the owners, and approve the data foundation. |
| Length | 12 slides. |
| Source material | None. Every number is illustrative and is labelled so on the slide. |
| Required sections | Where finance stands, where AI helps, the data foundation, the plan, the decisions. |
| Branding | VOLT default (assets/theme.json). |
| Output | Editable .pptx and a contact sheet. |

Slide 9 rebuilds a client data-architecture slide ("Step 3: extend existing data domains and products") with that
slide's own wording. It tags an item's status only where the slide's text states it. The other items are left
untagged rather than guessed.

## Example invocations

- "Use the consulting PPT template to build a 10-slide steering committee deck on our close transformation from
  these notes."
- "Turn this VOLT board pack into a consulting-style deck: keep every number, fix the layout."
- "Make a business case deck for an AI-enabled FP&A programme for the CFO. There's no data yet, so label
  everything as illustrative."
- "Rebuild this architecture slide on the consulting template, with the status legend and the takeaway stats."
