# Layout catalogue

Placeholder indexes: `0` title, `1` main body or chart area, `10+2k` heading of cell k, `11+2k` body of cell k,
`30+k` chart of cell k, `40` to `43` extras (legend, axis labels), `90` source line. In a storyboard, `"cells"` fill
10+2k and 11+2k in order; `"placeholders"` sets any index directly.

| Layout | Use for | Placeholders | Content limit |
|---|---|---|---|
| Cover | First slide | 0 title, 1 subtitle, 13 prepared for, 14 tag | Title up to about 12 words |
| Section Divider | Opening a part | 0, 1 subtitle, 13 number ("01") | One line each |
| Executive Summary | The whole story on one page | 0 (navy panel), 13 decision, 1 bullets | 4 to 5 bullets, bold lead-ins |
| Title and Content | Tables (risks, appendix), plain text | 0, 1 | Table up to about 10 rows at 12pt |
| Single Insight | One number or claim with support | 0, 10 stat, 11 support, 1 detail | Stat up to 6 characters |
| Two Column | Two lists or a chart and text | 0, 10/11, 12/13 | 6 bullets a column |
| Current vs Future | Today versus target | 0, 10/11 today, 12/13 target | 4 to 6 paired bullets |
| Three Pillars | Three themes | 0, cells 0 to 2 | 3 to 4 bullets each |
| Three Charts | Three small charts | 0, cells 0 to 2, 30 to 32 charts | One message per chart |
| Four Points | Four numbered points | 0, cells 0 to 3 | 2 to 3 lines each |
| KPI Dashboard | Up to four KPIs | 0, cells 0 to 3 (value, label, basis), 1 note | Value up to 7 characters |
| Chart with Takeaways | Bar, line, donut, waterfall | 0, 1 chart, 10 panel title, 11 takeaways | 3 takeaways |
| Prioritisation Matrix | 2x2 | 0, cells 0 to 3 (top left, top right, bottom left, bottom right), 40/41 axes, 1 notes | 3 items a quadrant |
| Process Flow | Up to six steps | 0, cells 0 to 5 (chevrons and text), 1 controls and enablers | 2 lines a step |
| Roadmap | Four phases | 0, cells 0 to 3 | 2 to 3 items a phase |
| Recommendations and Decisions | Last slide | 0, 1 recommendations, 10/11 decisions panel | 3 of each, with owners |
| Data Architecture Flow | Sources, Silver, Gold, use cases, takeaway | 0, 40 legend, cells 0 to 5 (cell 5 is the takeaway panel) | 10 items a column; status tags |

Bar, line, donut, waterfall, risk and appendix-table slides use Chart with Takeaways or Title and Content: the chart or
table type comes from the storyboard, not from a separate layout.
