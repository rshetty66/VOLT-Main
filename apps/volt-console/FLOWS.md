# Reference navigation checks

| Start | Action | Expected |
| --- | --- | --- |
| Main rail, desktop or phone | Open Reference | One Reference rail entry, no separate Agents or Skills entry; Agent Registry and Skill Finder controls fit or wrap. |
| Agent Registry | Search by keyword or filter by layer; open an agent | The registry filters its cards and the selected agent's details open. |
| Agent details | Choose Chat with the agent | Console opens with that agent selected; the chat agent picker remains available. |
| Reference | Choose Skill Finder; search for a task, open a skill, and return | The results list, skill content and Back to results work. |
| Console or another view | Check the top bar, then use Reference to open Skill Finder | No standalone directory shortcut appears in the top bar; Skill Finder opens within Reference. |
| Reference | Open Help, then use a checklist action | Console reopens the checklist and the action opens its usual destination. |
