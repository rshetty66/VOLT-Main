# React Bits license summary

This is a plain-language summary for VOLT practitioners, not legal advice. The license text governs. Source:
<https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md>, read on 2026-11-04.

React Bits uses **MIT + Commons Clause License Condition v1.0**, copyright David Haz.

## Allowed

- Using, copying, modifying, merging, publishing and distributing the components **as part of an application,
  website or product**, including commercial and paid ones.
- Using what the React Bits tools export (code, images, video, audio) in any personal or commercial product.

Keep the copyright and permission notice in all copies or substantial portions.

## Not allowed

- Selling, sublicensing or redistributing **the components themselves**, alone, in a bundle or as a ported version.
- The same for the React Bits tools (Background Studio, Texture Lab, Shape Magic, Center Stage, Sound Lab and later
  tools) and the sound library, and offering the tools or a close copy of them as a hosted service.
- Selling or redistributing exports on their own, for example as a sound, texture, background or template pack.

## What this means for VOLT

- The VOLT plugin is redistributed, so it holds **no React Bits source**. It holds only this method and its
  guardrails.
- Components are added inside each client application at build time, which the license permits.
- Do not build a "VOLT animated components" pack, starter kit or template from React Bits code.
- When in doubt about a client deliverable, for example a reusable accelerator handed to the client, ask the
  engagement's legal or risk contact before shipping.
